# Phishing Awareness Simulator

An interactive cybersecurity training platform that helps users recognize common phishing signals and distinguish suspicious messages from routine workplace email.

## Objectives

- Practice identifying phishing attempts in a safe, browser-only environment.
- Learn to examine sender details, tone, context, and unusual requests.
- Demonstrate a lightweight, accessible static web application suitable for a portfolio.

## Features

- Ten mixed questions: five fictional email scenarios and five practical phishing-awareness challenges.
- Multiple-choice exercises on unexpected requests, sender verification, QR codes, and multi-factor authentication.
- Immediate answer feedback, explanations, and scenario-specific signals.
- Score, accuracy, and training progress tracking.
- Results summary, cybersecurity recommendations, and restart flow.
- Responsive layout for desktop, tablet, and mobile.
- No backend, account, personal data collection, real email, or clickable phishing links.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

The files are kept in the repository root so they can be selected and uploaded together in the GitHub web interface.

## Run locally

Open `index.html` in a modern browser. No build step or server is required.

## Deploy with GitHub Pages

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch and `/ (root)` folder, then save.
5. Open the Pages URL shown in the repository settings.

The application uses relative paths, so the project can be hosted as a static site.
